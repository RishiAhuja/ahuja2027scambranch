# Fictional entities

Use only these names in scenario cards. Fraud and legitimate cases in a family use the **same** organisation name so the brand name cannot predict the label.

Links use the `.invalid` TLD, which can never resolve. Numbers are placeholders filled at generation time from a fictional pool.

## Placeholders

| Placeholder | Meaning |
|---|---|
| `[PHONE_n]` | Fictional phone number |
| `[ACCT_LAST4]` | Last four digits of an account or card |
| `[UPI_ID_n]` | Fictional UPI handle |
| `[AMOUNT_n]` | Rupee amount, chosen from the range given in the card |
| `[ORDER_ID]`, `[AWB_ID]`, `[TICKET_ID]` | Order, airway-bill, or support ticket number |
| `[PERSON_NAME]` | Recipient's name, sampled per conversation |
| `[AGENT_NAME]` | Caller's stated name |
| `[CITY]` | Indian city appropriate to the language pair |
| `[LICENCE_ID]` | Recruiting-agent licence number |
| `[N]` | Small count stated in the card (for example 3–5 students) |
| `https://<name>.invalid/...` | Any link |
